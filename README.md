
# GEO4120-ERT-2026

## Installation

### 1. Create a Conda Environment

```bash
conda create -n pg python=3.12
```

### 2. Activate the Environment

```bash
conda activate pg
```

### 3. Install pyGIMLi

We recommend installing `pygimli` using pip, as the Conda Forge installation may not work.

```bash
pip install pygimli
```

### 4. Install JupyterLab

```bash
conda install -c conda-forge jupyterlab
```

### 5. Install Additional Packages

Install the additional packages using pip:

```bash
pip install numpy matplotlib scipy
```

Alternatively, use Conda Forge:

```bash
conda install -c conda-forge numpy matplotlib scipy
```
